FREQUENTLY AUDITED QUESTIONS

HOW DOES GAPLINE CALCULATE DETERMINISTIC MATCH SCORES?
GAPLINE constructs an abstract syntax tree of both the candidate document and target requisition. It scores matches along 6 discrete vector dimensions (hard skills, seniority level, metric density, keyword frequencies, temporal gaps, and parser syntax) using explicit deterministic taxonomy rules.
WHY DOES RED NEVER APPEAR AS A BACKGROUND OR BUTTON COLOR?
Under our strict brutalist design system, red is strictly rationed for match scores, missing skill void markers, meter fills, active cue borders, and artifact specimen values. It is never used decoratively.
HOW DOES GAPLINE DETECT SENIORITY DISPARITY?
Pass 02 evaluates title scopes against engineering ladder heuristics, comparing scope indicators (e.g. cross-org architectural leadership vs single-feature execution) to identify when candidate experience is under-calibrated for Staff/Principal postings.
DO YOU STORE OR SHARE UPLOADED RESUME DOCUMENTS?
No. All lexical AST extraction and gap analysis executes client-side in deterministic memory buffers. Zero resume text is saved to remote third-party databases.
HOW DO WEAK LINE REWRITES GENERATE IMPACT METRICS?
The engine identifies passive duty descriptions (e.g., "responsible for backend APIs") and converts them into structured action-metric-result statements calibrated with latency, scale, and cost deliverables.
